WebMemories · 网页记忆

隐私政策

最后更新：2026 年 10 月 29 日 · 适用于 WebMemories 浏览器扩展当前版本

WebMemories 帮助您保存网页片段、手动对比内容变化，以及保存和恢复浏览现场。本政策说明扩展如何访问、使用和保存数据。

1. 访问及保存的数据

  • 网页记忆：当您主动保存或检查选区时，扩展读取网页标题、网址、所选区域的文字、图片地址和替代文字、选区定位信息，并尝试截取选区当前可见部分的截图。本机记录包含保存基准、最近检查结果、时间、变化状态及您填写的备注。
  • 浏览现场：当您打开现场编辑器、刷新或保存时，扩展读取普通浏览窗口及标签页的标题、网址、顺序和活动状态，保存您选择的标签页以及您填写的现场名称和进度。不读取无痕窗口中的标签页。

网页文字、截图、网址参数和手动备注可能包含个人或敏感信息，请谨慎选择保存内容。扩展不专门提取 Cookie、密码或登录凭证，但不能保证您选中的内容不包含这些信息。

2. 使用目的

上述数据仅用于展示已保存的内容、重新定位网页区域、对比变化，以及按您保存的顺序恢复网页和显示工作进度。扩展不持续监控浏览历史，也不提供后台定时检查。

3. 本地存储与数据共享

扩展数据使用浏览器的 chrome.storage.local 保存在当前浏览器配置文件中，不使用 chrome.storage.sync，不由扩展上传到开发者服务器，不提供云同步。当前版本无需账号，不含广告、分析或遥测服务，也不会向开发者或第三方出售或提供已保存的内容。

当您打开原网页或恢复浏览现场时，浏览器会按通常方式访问相应网站。这些网站可能按照其自身隐私政策处理访问数据。

4. 权限用途

  • storage：保存和读取本机网页记忆与浏览现场。
  • activeTab：在您主动操作时，临时访问当前网页并进行截图。
  • scripting：在目标网页中运行选区与检查工具。
  • tabs：为浏览现场功能读取标签页标题和网址，以及打开、恢复网页。

5. 保存期限与删除

记录保留到您在扩展中删除它们，或浏览器移除对应扩展数据为止。您可以分别在“网页记忆”和“浏览现场”中删除记录。更新基准会替换旧基准；新的检查结果会替换上一份检查结果。卸载扩展通常会删除其本地数据。当前版本不支持数据导入或导出。

6. 本政策网页的托管

本网页由 GitHub Pages 托管，没有添加统计脚本、广告或表单。访问本网页时，GitHub 可能处理 IP 地址等技术信息，具体见 GitHub 隐私声明。这与扩展保存在您本机的记录是分开的。

7. 政策更新

功能或数据处理方式发生变化时，我们将更新本政策和更新日期。如涉及新增数据用途或权限，也会按浏览器和商店要求提供相应说明或授权流程。

8. 联系与反馈

您可以通过 WebMemories GitHub Issues 提交问题。Issues 是公开页面，请勿提交截图原文、密码、私人网址或其他敏感信息。
